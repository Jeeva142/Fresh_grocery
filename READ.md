# FreshCart 🛒

FreshCart is a full-stack grocery e-commerce web application.

## 🚀 Features
- User Login & Register
- Product Listing
- Cart System
- Responsive Navbar
- Wishlist
- Orders Page

## 🛠 Tech Stack
### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Spring Boot
- MySQL
- Spring Data JPA

## 📦 Products
- Tomato
- Onion
- Potato
- Carrot
- Brinjal
and more...
